Shoreline Buildings API

This application holds data about shoreline buildings in Sweden. It contains the number of buildings counted at shorelines in Sweden and reported per region, building type, shoreline type, area type and year.

Please note that the application only provides the data in Swedish.

It exposes a GraphQL API to search for the data.

It uses a REST API with JWT (Json Web Token) for authentication.

Data source

Data set: Byggnader i strandnära läge efter region och byggnadstyp. År 2018 - 2023 (Shoreline buildings by region and type of building. Year 2018 - 2023)

Source: Statistics Sweden

Usage

URL for the buildings API: https://cu3156.camp.lnu.se/api/graphql

URL for the authentication API: https://cu3156.camp.lnu.se/api/auth

More documentation, complete with example requests and responses can be found in Postman (Note: loads slowly)

Testing the API

The API has a playground where you can test it: Playground to test the API

You need to register and log in to be able to create, update and delete resources. Follow the instructions in Authentication for the Shoreline Buildings API to do so.

Please note that a token only is valid for five minutes.

Description of the data

Field Description Types Note
id The current item's id.
region The current item's region, specified with region code, name and region type.
  • riket
  • län
  • kommun
buildingType The current item's building type, specified with id and name.
  • bostad
  • industri
  • samhällsfunktion
  • verksamhet
  • ekonomibyggndad
  • komplementbyggnad
  • övrig byggnad
  • totalt
shorelineType The current item's shoreline type, specified with id and name.
  • hav
  • inlandsvatten
  • totalt
areaType The current item's area type, specified with id and name.
  • inom tätort
  • inom formellt skyddad natur
  • totalt
 Only the area types "inom tätort" and "inom formellt skyddad natur" are separately identified. All other areas types are included in the total amount without further specification. Therefore, the numbers for "inom tätort" and "inom formellt skyddad natur" will not add upp to "totalt".
year The year the current item's building count applies to.
buildingCount The number of shoreline buildings.
createdAt Date and time for when the item was created.
updatedAt Date and time for when the item was updated.
